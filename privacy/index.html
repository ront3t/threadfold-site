Privacy policy · 1 November 2026

Your chats stay in this browser.

Threadfold is a Chrome extension that organizes conversations on ChatGPT, Claude, Gemini, and Grok. It has no account system and no application server. The notes you save do not pass through the publisher, because there is no publisher server for that data.

Contact: ront3t@gmail.com

What is stored on the device

Threadfold writes one library in chrome.storage.local on this browser profile:

  • Folder names, tags, and which saved chat sits in which folder.
  • Conversation titles, URLs, and snippets you choose to save. Full transcripts are not stored.
  • Prompts you save, including their text.
  • Your language choice.
  • A license key, if you enter one, plus the plan status and a random install id.

Storage is local, not Chrome sync. Threadfold does not upload that library to Google, to the chat sites, or to a backend of its own. Export files (Markdown, and the print view used for PDF) are created on this device.

What is not collected

  • No analytics, advertising, or crash-reporting SDK.
  • No account, and no copy of your chat history.
  • The extension does not read pages other than ChatGPT, Claude, Gemini, and Grok.
  • It reads a conversation’s messages only when you export the open chat, and that text stays in the export file.

License checks

The build offered for install uses a local license check and does not contact a license server. If a later build is switched to Lemon Squeezy, activating or rechecking a key sends only that key and an install id to api.lemonsqueezy.com. Lemon Squeezy would be the seller of record. Chat text, titles, snippets, and prompts are not part of that request. The extension does not contain a Lemon Squeezy API secret.

Permissions

  • storage — the local library described above, plus a short-lived export payload in session storage.
  • Host access to the four chat sites — so the panel can read the conversation list that is already on screen, insert a prompt, and export the open chat.
  • Host access to api.lemonsqueezy.com — declared so a paid build can check a license key. The current build’s local checker does not call it.

Children

Threadfold is not directed at children under 13, and it does not knowingly collect personal information from them.
